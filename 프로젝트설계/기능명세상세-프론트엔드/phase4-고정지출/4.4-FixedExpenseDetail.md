**없는 대상이면 모달을 열지 않는다.** 빈 모달을 띄우지 말고 **목록만** 남긴 뒤 안내한다.
**없는 것과 남의 것을 가르지 않는다.**

값을 들여다보다가 삭제를 누르는 자리를 만들지 않는다.

## 이름은 저장되지 않고 현재 값이 온다

수단·지출유형 이름은 **조회 시점 현재 이름**이다. 고정지출에는 **이름 컬럼이 없어** 조회할
때마다 수단·지출유형 행에서 읽는다.

**같은 설정을 수단 이름 변경 전후로 열면 값이 달라진다.** 저장된 이름이 없기 때문이며
**이것이 의도한 동작이다.**

### 010 과 정반대다

| | 지출·소득 (010) | **고정지출 (이 화면)** |
|---|---|---|
| 이름의 출처 | **등록 당시 스냅샷** | **조회 시점 현재 값** |
| 수단 이름을 바꾸면 | 과거 기록은 그대로 | **이 설정도 새 이름으로 보인다** |
| 왜 | **이미 일어난 일의 기록** | **지금 유효한 설정** |
| 화면이 할 일 | 받은 값 그대로 | **받은 값 그대로** |

**화면이 할 일은 양쪽 다 같다 — 받은 값 그대로.** 저장된 값으로 덮어쓰지도, ID 로 원본을
다시 조회하지도 않는다.

**010 의 가계부 목록에서 고정지출 행만 현재 이름이었던 것**이 바로 이 차이다.

**사용자에게 설명하지 않는다.** 모달에 「이 이름은 현재 값입니다」 같은 주석을 달면 읽기
어려워진다 — 규칙은 문서에 남기고 화면은 조용히 지킨다.

상세 필드: [기능명세상세-백엔드](../../기능명세상세-백엔드/README.md)

| 시점 | API 이름 | Method | 용도 |
|------|----------|--------|------|
| 모달이 열릴 때 | `FixedExpenseGet` | GET | **목록을 그리기 전에** 그 설정을 조회해 모달에 싣는다. 수단·유형 이름이 **현재 값**으로 함께 온다 |

**삭제를 부르지 않는다.** 이 모달에 삭제 버튼이 없으며, 삭제는 목록(4.2)이 맡는다.

**선택 목록도 부르지 않는다.** 읽기 전용이라 고를 것이 없다.

## 검증·안내

| 대상 | 규칙·문구 |
|------|-----------|
| **이름 표시** | **받은 값 그대로**다. 수단·유형 이름은 **조회 시점 현재 값**이며 화면이 저장된 값으로 덮어쓰지 않는다 |
| 010 과 반대 | 지출·소득은 **등록 당시 스냅샷**이라 덮어쓰면 안 됐고, 고정지출은 **현재 이름**이라 옛 이름을 들고 있으면 안 된다 — **화면이 할 일은 양쪽 다 같다** |
| 이름 규칙의 안내 | **사용자에게 설명하지 않는다.** 주석을 달면 읽기 어려워진다. 규칙은 문서에 남기고 화면은 조용히 지킨다 |
| **금액의 이름** | **「기본 금액」**으로 적는다. 4.6 의 **「그 달 금액」과 다르다** |
| **적용 기간 표시** | 「2026-01 ~ 2026-12」로 한 줄에 보인다. 저장은 정수 네 칸이지만 **읽는 자리에서는 이어 붙인다** |
| **읽기 전용** | 입력 칸을 두지 않는다. 고치는 것은 4.5 다 |
| **삭제 버튼 없음** | 값을 들여다보다가 **되돌릴 수 없는 동작을 누르는 자리**를 만들지 않는다. 삭제는 목록 행의 버튼이 확인 다이얼로그를 거쳐 처리한다 |
| **없는 대상** | **모달을 열지 않고 목록만 남긴다.** 빈 모달을 띄우지 않는다 |
| 없는 것과 남의 것 | **가르지 않는다.** 가르면 식별자를 훑어 남의 고정지출이 실재하는지 알아낼 수 있다 |
| 고정지출을 찾을 수 없음 | 모달 없이 **목록의 안내**로 보인다 |
| 실패 안내 문구 | 백엔드가 준 문구를 그대로 쓴다 |
| 백엔드 불통 | 007 의 오류 화면으로 간다 |

### 여기서 볼 수 없는 것

| 값 | 어디서 보나 |
|---|---|
| **그 달 금액·결제일** | **4.6 월별 내역.** 설정과 다른 저장 단위다 |
| **직접 고쳤는지** | 4.6 의 「수정됨」 표시 |
| 이 설정이 만든 지출 내역 | 5.1 월별 가계부의 **고정지출 행** |

**설정과 그 달 내역은 다른 것이다.** 이 화면은 **「매달 이만큼 나간다」는 기준값**만 보인다.
