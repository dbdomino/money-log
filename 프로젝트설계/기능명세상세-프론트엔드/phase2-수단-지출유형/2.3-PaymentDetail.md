## 목적

## 진입

| 항목 | 내용 |
|------|------|
| 진입 경로 | 수단 목록(2.1) 행의 「상세」 버튼, 또는 브라우저가 `?m=detail&id={식별자}` 가 붙은 주소를 직접 여는 경우 둘이다 |
| 미로그인 | **막는다.** 진입 판정이 로그인 화면으로 보낸다 |
| 권한 없음 | 해당 없음 — 본인 것만 조회되는 것은 백엔드가 보장한다 |

**모달을 열기 전에 서버가 대상을 조회한다.** 여는 일만 브라우저가 하면 열린 모달이 빈 채로 뜨고, 값을 채우려면 브라우저가 다시 요청해야 한다.

| 주소의 상태 | 이 화면이 하는 일 |
|------|------|
| `?m=detail&id={있는 식별자}` | 그 수단을 조회해 모달에 값을 채우고 목록 위에 연다 |
| `?m=detail&id={없는 식별자}` 또는 **남의 식별자** | **오류 화면이 아니라** 모달 없이 목록만 보이고 안내를 띄운다. 낡은 북마크일 뿐이고 목록은 정상이다 |
| 식별자 없이 `?m=detail` | 모달을 열지 않고 목록만 보인다. 무엇을 보여 줄지 모르는 상태다 |

**없는 것과 남의 것을 가르지 않는다.** 백엔드가 한 코드로 묶었고 화면도 풀지 않는다 — 가르면 식별자를 훑어 남의 수단이 실재하는지 알아낼 수 있다.

## 화면 구성

### 영역

| 영역 | 설명 |
|------|------|
| 부모 목록 | 수단 목록(2.1)이 평소대로 뒤에 그려진다 |
| 모달 머리 | 제목 「수단 상세」와 닫기 버튼을 놓는다 |
| 값 영역 | 값 여섯을 이름과 함께 글로 보인다. **입력 칸을 두지 않는다** |
| 모달 바닥 | 「닫기」와 「수정」 버튼을 놓는다 |

### 입력·표시 요소

| 요소 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 이름 | 문구 | 필수 | 수단 이름 |
| 구분 | 문구 | 필수 | 「카드」 또는 「계좌」. 영문 코드를 그대로 보이지 않는다 |
| 용도 | 문구 | 필수 | 「지출용」 또는 「소득용」 |
| 사용 여부 | 문구 | 필수 | 「사용」 또는 「사용 안 함」 |
| 상태 | 문구 | 필수 | 「정상」 또는 「삭제됨」. 삭제된 수단도 이 모달로 열 수 있다 |
| 카드 유효기간 | 문구 | — | `YYYY-MM`. **구분이 카드일 때만** 보인다. 목록에는 이 열이 없어 여기가 유효기간을 확인하는 유일한 자리다 |
| 「수정」 버튼 | 링크 버튼 | 필수 | 수정 모달 주소(`?m=edit&id={식별자}`)로 **이동한다**. 이 모달 안에서 칸이 열리지 않는다 |
| 「닫기」 버튼 | 버튼 | 필수 | 모달을 닫고 목록으로 돌아간다 |

**입력 칸이 없다.** 한 모달에서 읽기와 고치기를 겸하면 「지금 고칠 수 있는 상태인가」를 사용자가 매번 판단해야 한다.

**저장하는 API 가 없다.** 읽기 전용 화면이다.

## 동작

| 사용자 행동 | 프론트 처리 | 성공 시 | 실패 시 |
|-------------|-------------|---------|---------|
| 목록 행의 「상세」를 누른다 | 주소에 모달 값과 식별자를 실어 목록을 다시 열고, **목록을 그리기 전에** 그 수단을 조회한다 | 값이 채워진 상세 모달이 목록 위에 뜬다 | 조회가 실패하면 **모달 없이 목록만** 보이고 안내를 띄운다 |
| 「수정」을 누른다 | 수정 모달 주소로 이동한다. **주소가 바뀐다** | 수정 모달이 열린다 | (해당 없음 — 이동만 한다) |
| 「닫기」를 누르거나 모달을 닫는다 | 모달을 닫고 목록만 남긴다 | 목록이 뜬다 | (해당 없음) |
| 주소에 없는 식별자를 친다 | 조회가 실패한다 | (해당 없음) | 오류 화면이 아니라 목록이 정상으로 뜨고 안내가 보인다 |

## 검증·안내

| 대상 | 규칙·문구 |
|------|-----------|
| 입력 검증 | 입력 요소가 없어 검증할 대상이 없다 |
| 수단 없음·타인 소유 | **모달 없이 목록만** 보이고 안내를 띄운다. 오류 화면으로 보내지 않는다 — 낡은 북마크일 뿐이고 목록은 정상이다 |
| 존재 여부 노출 | **없는 것과 남의 것을 화면이 가르지 않는다.** 백엔드가 한 코드로 묶은 이유를 화면이 풀지 않는다 |
| 유효기간 표시 | 구분이 카드일 때만 보인다. 계좌인데 빈 칸으로 두면 「유효기간을 모르는 계좌」로 읽힌다 |
| 모달 안의 모달 | **열지 않는다.** 「수정」은 주소로 이동하며, 007 의 모달 셸이 겹침을 다루지 않고 겹치면 Esc 한 번에 어느 것이 닫히는지 규칙이 필요해진다 |
| 실패 안내 문구 | 백엔드가 준 문구를 그대로 쓴다 |
| 백엔드 불통 | 007 의 오류 화면으로 간다 |

## 비고

- 이 모달은 부모 목록(2.1)의 템플릿 안에 있다. 별도 주소를 갖지 않는다.
- 지출유형 상세(2.7)와 같은 모양이다. 두 화면이 같은 규칙을 쓴다.
