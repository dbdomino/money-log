## 목적

- 지출유형 하나의 값과 아이콘을 읽기 전용으로 확인하고, 필요하면 수정으로 넘어간다.

## 진입

| 항목 | 내용 |
|------|------|
| 진입 경로 | 지출유형 목록(2.5) 행의 「상세」 버튼, 또는 브라우저가 `?m=detail&id={식별자}` 가 붙은 주소를 직접 여는 경우 둘이다 |
| 미로그인 | **막는다.** 진입 판정이 로그인 화면으로 보낸다 |
| 권한 없음 | 해당 없음 — 본인 것만 조회되는 것은 백엔드가 보장한다 |

**모달을 열기 전에 서버가 대상을 조회한다.** 진입 규칙은 수단 상세(2.3)와 같다.

| 주소의 상태 | 이 화면이 하는 일 |
|------|------|
| `?m=detail&id={있는 식별자}` | 그 유형을 조회해 모달에 값을 채우고 목록 위에 연다 |
| `?m=detail&id={없는 식별자}` 또는 **남의 식별자** | **오류 화면이 아니라** 모달 없이 목록만 보이고 안내를 띄운다 |
| 식별자 없이 `?m=detail` | 모달을 열지 않고 목록만 보인다 |

**없는 것과 남의 것을 가르지 않는다.** 가르면 식별자를 훑어 남의 유형이 실재하는지 알아낼 수 있다.

## 화면 구성

### 영역

| 영역 | 설명 |
|------|------|
| 부모 목록 | 지출유형 목록(2.5)이 평소대로 뒤에 그려진다 |
| 모달 머리 | 제목 「지출유형 상세」와 닫기 버튼을 놓는다 |
| 아이콘 | 값 영역 위에 아이콘 이미지를 크게 놓는다. 없으면 대체 표시를 그린다 |
| 값 영역 | 값 넷을 이름과 함께 글로 보인다. **입력 칸을 두지 않는다** |
| 모달 바닥 | 「닫기」와 「수정」 버튼을 놓는다 |

### 입력·표시 요소

| 요소 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 아이콘 | 이미지 | — | 유형의 아이콘. **화면 모듈 주소로 건다.** 없으면 이미지를 걸지 않고 대체 표시를 그린다 |
| 이름 | 문구 | 필수 | 유형 이름 |
| 구분 | 문구 | 필수 | 「기본」 또는 「직접 만듦」. **기본이면 이름을 바꿀 수 없고 지울 수 없다**는 것을 사용자가 이 값으로 안다 |
| 사용 여부 | 문구 | 필수 | 「사용」 또는 「사용 안 함」 |
| 상태 | 문구 | 필수 | 「정상」 또는 「삭제됨」. 삭제된 유형도 이 모달로 열 수 있다 |
| 「수정」 버튼 | 링크 버튼 | 필수 | 수정 모달 주소(`?m=edit&id={식별자}`)로 **이동한다**. 이 모달 안에서 칸이 열리지 않는다 |
| 「닫기」 버튼 | 버튼 | 필수 | 모달을 닫고 목록으로 돌아간다 |
| 대체 표시 | 문구·도형 | — | 아이콘이 없을 때 그 자리에 보인다 |

**입력 칸이 없다.** 한 모달에서 읽기와 고치기를 겸하면 「지금 고칠 수 있는 상태인가」를 사용자가 매번 판단해야 한다.

## 호출 API

상세 필드: [기능명세상세-백엔드](../../기능명세상세-백엔드/README.md)

| 시점 | API 이름 | Method | 용도 |
|------|----------|--------|------|
| 모달이 열리기 전 | `ExpendGroupGet` | GET | 대상 유형의 이름·사용 여부·삭제 여부·기본 유형 여부·아이콘 주소를 받는다 |
| 아이콘을 그릴 때 | `ExpendGroupIconGet` | GET | 이미지 바이너리를 받는다. **화면이 직접 부르지 않는다** — 007 의 중계가 인증을 실어 대신 부른다 |

**저장하는 API 가 없다.** 읽기 전용 화면이다.

## 동작

| 사용자 행동 | 프론트 처리 | 성공 시 | 실패 시 |
|-------------|-------------|---------|---------|
| 목록 행의 「상세」를 누른다 | **목록을 그리기 전에** 그 유형을 조회하고 아이콘 주소에서 파일명을 꺼낸다 | 값과 아이콘이 채워진 상세 모달이 뜬다 | 조회가 실패하면 **모달 없이 목록만** 보이고 안내를 띄운다 |
| 아이콘이 없는 유형을 연다 | 이미지를 걸지 않고 대체 표시를 그린다 | 자리가 깨지지 않는다 | (해당 없음) |
| 「수정」을 누른다 | 수정 모달 주소로 이동한다. **주소가 바뀐다** | 수정 모달이 열린다 | (해당 없음 — 이동만 한다) |
| 「닫기」를 누르거나 모달을 닫는다 | 모달을 닫고 목록만 남긴다 | 목록이 뜬다 | (해당 없음) |
| 주소에 없는 식별자를 친다 | 조회가 실패한다 | (해당 없음) | 오류 화면이 아니라 목록이 정상으로 뜨고 안내가 보인다 |

## 검증·안내

| 대상 | 규칙·문구 |
|------|-----------|
| 입력 검증 | 입력 요소가 없어 검증할 대상이 없다 |
| 유형 없음·타인 소유 | **모달 없이 목록만** 보이고 안내를 띄운다. 오류 화면으로 보내지 않는다 |
| 존재 여부 노출 | **없는 것과 남의 것을 화면이 가르지 않는다** |
| 아이콘 주소 | **화면 모듈 경로로 건다.** 백엔드 주소를 직접 걸면 인증이 붙지 않아 실패한다 |
| 아이콘 없음 | **이미지를 걸지 않고** 대체 표시를 그린다. 빈 주소를 건 이미지는 브라우저가 현재 페이지를 다시 받아 와 깨진 표시를 남긴다 |
| 구분 표시 | 「기본」·「직접 만듦」으로 보인다. 기본 유형이 왜 고칠 수 없는지를 사용자가 이 값으로 안다 |
| 모달 안의 모달 | **열지 않는다.** 「수정」은 주소로 이동한다 |
| 실패 안내 문구 | 백엔드가 준 문구를 그대로 쓴다 |
| 백엔드 불통 | 007 의 오류 화면으로 간다 |

## 비고

- 이 모달은 부모 목록(2.5)의 템플릿 안에 있다. 별도 주소를 갖지 않는다.
- 수단 상세(2.3)와 같은 모양이다. 다른 것은 **아이콘을 보인다**는 것 하나다.
