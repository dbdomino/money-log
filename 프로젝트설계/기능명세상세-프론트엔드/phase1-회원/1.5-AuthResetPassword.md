## 목적

- 찾기 성공 후 새 비밀번호를 설정한다.
- 변경 API 성공 후 **같은 카드**에 완료 안내를 보여 주고, 로그인 화면으로 보낸다.

## 진입

| 항목 | 내용 |
|------|------|
| 진입 경로 | 1.4 비밀번호 찾기 확인 성공 후 |
| 미로그인 | 접근 가능 (로그인 불필요) |
| 권한 없음 | 해당 없음 |

## 화면 구성

### 영역

| 영역 | 설명 |
|------|------|
| 입력 단계 | 새 비밀번호·확인 입력, 변경 버튼 |
| 성공 단계 | 같은 카드에 「비밀번호가 변경되었습니다」. 잠시 후(또는 버튼으로) `/auth/login` 이동 |

### 입력·표시 요소

| 요소 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 새 비밀번호 | password | Y | 변경할 비밀번호 |
| 새 비밀번호 확인 | password | Y | 위와 일치해야 함 |
| 성공 안내 | 문구 | — | 성공 시에만. 「비밀번호가 변경되었습니다」 |

## 호출 API

상세 필드: [기능명세상세-백엔드](../../기능명세상세-백엔드/README.md)

| 시점 | API 이름 | Method | 용도 |
|------|----------|--------|------|
| 변경 버튼 | `MemberResetPassword` | POST | 새 비밀번호 저장 |

## 동작

| 사용자 행동 | 프론트 처리 | 성공 시 | 실패 시 |
|-------------|-------------|---------|---------|
| 변경 클릭 | `MemberResetPassword` 호출 | 같은 화면에 완료 문구 표시 → 약 2초 후 `/auth/login` (즉시 「로그인으로」도 가능) | `resCode`·메시지 표시, 입력 단계 유지 |
| 로그인으로 | — | `/auth/login` | — |

## 검증·안내

| 대상 | 규칙·문구 |
|------|-----------|
| 비밀번호 | 8자 이상, 영·대·소·특수·숫자 중 3종류 이상 |
| 확인 | 새 비밀번호와 일치 |
