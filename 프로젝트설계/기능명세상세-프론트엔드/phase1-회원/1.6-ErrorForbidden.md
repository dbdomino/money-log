**레이아웃이 `auth` 인 이유**: 미로그인 사용자도 들어오는 화면이라 로그인 후 사이드바를 붙일 수 없다. `main` 을 쓰면 사이드바가 회원 권한을 필요로 하는데, 세션이 없거나 깨진 상태에서도 떠야 하는 화면이다. `화면기획/01-화면구성.md` 의 표와 `화면기획/proto/error-forbidden.html` 이 둘 다 `auth` 다.

## 목적

- 관리자 전용 URL 등에 권한 없이 접근했을 때 안내한다.

## 진입

| 항목 | 내용 |
|------|------|
| 진입 경로 | 관리자 URL 직접 접근·권한 부족 redirect 등 |
| 미로그인 | 접근 가능 (로그인 불필요) |
| 권한 없음 | 이 화면이 안내 본문 |

**미로그인은 여기로 오지 않는다.** 로그인하지 않은 사용자가 관리자 URL 로 들어오면 이 화면이 아니라 로그인 화면으로 보내진다. 이 화면은 **로그인은 했는데 권한이 모자란** 경우에만 보인다. 순서가 뒤집히면 미로그인 사용자에게 그 URL 이 실재한다는 사실이 드러난다.

## 화면 구성

### 영역

| 영역 | 설명 |
|------|------|
| 브랜드 | 카드 상단에 서비스 로고 `money-log` 를 놓는다. 로그인 화면과 같은 자리다 |
| 안내 | 제목 「권한 없음」과 안내 문구 한 줄을 가운데 정렬로 놓는다 |
| 이동 버튼 | 카드 하단에 버튼 두 개를 가로로 놓는다. 「가계부로」(보조)와 「로그인」(주) |

### 입력·표시 요소

| 요소 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| 제목 | 텍스트 | 필수 | 「권한 없음」 고정 문구. 서버에서 값을 넣지 않는다 |
| 안내 문구 | 텍스트 | 필수 | 「이 페이지에 접근할 권한이 없습니다.」 고정 문구. 어떤 URL 이 막혔는지 밝히지 않는다 |
| 「가계부로」 버튼 | 링크 버튼 | 필수 | 월별 가계부(`/ledger`)로 이동한다. 보조 스타일 |
| 「로그인」 버튼 | 링크 버튼 | 필수 | 로그인 화면(`/auth/login`)으로 이동한다. 주 스타일 |

**이 화면은 백엔드를 부르지 않는다.** 권한이 모자라 차단된 사용자에게 보여 줄 고정 안내이므로 가져올 데이터가 없다. 31개 화면 중 유일하게 API 를 호출하지 않는 화면이라 007 공통 기반이 직접 만든다.

## 동작

| 사용자 행동 | 프론트 처리 | 성공 시 | 실패 시 |
|-------------|-------------|---------|---------|
| 관리자 전용 URL 에 일반 권한으로 들어온다 | 진입 판정이 권한 부족을 확인하고 이 화면 주소로 보낸다 | 이 화면이 뜬다 | (해당 없음 — 서버 호출이 없다) |
| 이 화면 주소로 직접 들어온다 | 로그인 여부를 묻지 않고 그대로 그린다 | 이 화면이 뜬다 | (해당 없음) |
| 「가계부로」를 누른다 | 월별 가계부(`/ledger`)로 이동한다 | 월별 가계부가 뜬다 | 로그인이 풀렸으면 진입 판정이 로그인 화면으로 보낸다 |
| 「로그인」을 누른다 | 로그인 화면(`/auth/login`)으로 이동한다 | 로그인 화면이 뜬다 | (해당 없음) |

## 검증·안내

| 대상 | 규칙·문구 |
|------|-----------|
| 입력 검증 | 입력 요소가 없어 검증할 대상이 없다 |
| 안내 문구 | 「이 페이지에 접근할 권한이 없습니다.」 한 줄만 보여 준다. 필요한 권한 등급이나 막힌 주소를 밝히지 않는다 |
| 미로그인 접근 | 막지 않는다. 이 화면은 비로그인 허용 목록에 들어간다 — 권한 차단이 착지할 곳 자체가 막혀 있으면 안내가 불가능하다 |
| 오류 표시 | 서버 호출이 없어 실패 안내를 띄울 경우가 없다 |

## 비고

- 화면 구성은 `화면기획/proto/error-forbidden.html` 을 옮긴다. 프로토타입의 상대경로 링크는 실제 화면 주소(`/ledger`·`/auth/login`)로 바꾼다.
- 007 공통 기반이 만드는 유일한 화면이다. 권한 차단이 착지할 화면이 없으면 진입 판정을 완성할 수 없어 인터셉터와 함께 서야 한다.
