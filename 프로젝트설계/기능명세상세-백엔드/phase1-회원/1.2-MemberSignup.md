## 응답

공통 래퍼: [_공통.md § 응답 래퍼](../_공통.md#응답-래퍼)

### 성공 (`resCode: 200`) — `data`

| 필드 | 타입 | 설명 |
|------|------|------|
| `memberId` | string | 가입된 아이디 |
| `nickname` | string | 닉네임 |
| `role` | number | `3` (일반 회원) |

비밀번호는 응답에 포함하지 않는다.

### 실패 — 대표 `resCode`

| resCode | 조건 |
|---------|------|
| 2002 | 아이디 중복 |
| 2003 | 이메일 중복 (email 제공 시) |
| 2004 | 비밀번호 규칙 위반 |
| 2005 | 비밀번호 확인 불일치 |
| 9001 | 필수 필드 누락·형식 오류 |

## 예시

### 성공

**Request**

```http
POST /api/v1/auth/signup HTTP/1.1
Host: localhost:8081
Content-Type: application/json

{
  "memberId": "user01",
  "password": "Passw0rd!",
  "passwordConfirm": "Passw0rd!",
  "nickname": "가계부초보",
  "email": "user01@example.com"
}
```

**Response**

```json
{
  "resCode": 200,
  "data": {
    "memberId": "user01",
    "nickname": "가계부초보",
    "role": 3
  }
}
```

### 실패

```json
{
  "resCode": 2002,
  "data": {
    "message": "이미 사용 중인 아이디입니다"
  }
}
```

## 비고

- 가입 성공 시 **권한은 일반(3)** 으로 저장한다.
- **기본 지출유형 10종**을 내부 로직으로 자동 등록한다 (Phase 2 API 전 선행 처리). 확정 목록은 **식비·교통·주거·통신·쇼핑·장보기·의료·교육·문화·기타**이며, "등"으로 열어 두지 않는다 — 회원마다 같은 목록이 생겨야 유형 이름이 화면·통계에서 일관되게 읽힌다.
- 10종은 `tbl_user_expend_group`에 `default_group = true`로 들어간다. 이 표시가 붙은 유형은 **삭제할 수 없다**(2.12의 `3107`).
- 함께 **30×30 기본 아이콘 PNG**를 회원별로 복사한다. 템플릿은 `app-mod/money-backend-app/src/main/resources/seed/expend-group-icons/`에 10개가 커밋되어 있고, 복사본 이름은 **`{id_key}_{expendGroupId}.png`** 다 — `{id_key}`는 `tbl_user`의 대리키, `{expendGroupId}`는 방금 만든 `tbl_user_expend_group.idx`다. 로그인 아이디(`user_id`)와 유형 이름은 파일명에 쓰지 않는다: 아이디를 넣으면 자식 데이터에 로그인 아이디를 복사하는 것이 되고, 유형 이름을 넣으면 이름의 `/`·`..`·공백이 조회 URL 경로에 그대로 실린다. DB에는 **파일명만** 저장하며(`icon_filename`), 조회 경로 `/api/v1/expend-groups/icons/{filename}`는 응답을 만들 때 앞에 붙인다 — 경로를 저장하면 Base URL이 바뀔 때 전 행을 고쳐야 한다.
- 이 10종은 **회원마다 생기는 데이터**라 스키마 덤프(`sql/schema-moneylogdb.sql`)의 시드에 넣지 않는다.
- 비밀번호 규칙: **8자 이상**, 영문 대·소문자·숫자·특수문자 중 **3종류 이상**.
- **저장**: 요청 Body의 `password` 평문을 검증한 뒤 **bcrypt** 로 해시해 `tbl_member.pw`에 저장. cost factor 등은 [_공통.md § 비밀번호 저장](../_공통.md#비밀번호-저장--bcrypt) 참고.
- 이메일·전화번호는 nullable. 미입력 시 `null` 저장.
- 전화번호는 **하이픈(-) 없이 숫자만** 입력·저장 ([_공통 § 전화번호](../_공통.md#전화번호-형식)).
