# [백엔드] 월별 고정지출 내역 단건 수정

> API: `FixedExpenseMonthlyUpdate` · Phase 4 · 기능번호 4.6  
> 인덱스: [README.md](../README.md)

## 메타

| 항목 | 내용 |
|------|------|
| Phase | 4 (가계부·고정지출) |
| 기능 이름 | 월별 고정지출 내역 단건 수정 |
| 기능번호 | 4.6 |
| API 이름 | `FixedExpenseMonthlyUpdate` |
| Method | `PATCH` |
| URL | `/api/v1/fixed-expenses/monthly/{year}/{month}/{fixedExpenseId}` |
| 권한 | 로그인 |
| Content-Type | `application/json` |

## 요청

### Path Variables

| 이름 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| `year` | number | ✅ | 연도 |
| `month` | number | ✅ | 월 1~12 |
| `fixedExpenseId` | number | ✅ | 고정지출 관리 PK |

> 세 값이 월별 고정지출 내역의 **복합키**다. 세그먼트 순서는 `ExpendTargetMonthlyUpsert`(`/expend-targets/monthly/{year}/{month}/{expendGroupId}`)와 같게 맞췄다.

### Body

보낸 필드만 바뀐다(부분 수정). 하나도 안 보내면 `3401`.

| 필드 | 타입 | 필수 | 설명 |
|------|------|:----:|------|
| `amount` | number | ❌ | 그 달 금액. 0보다 커야 한다 |
| `paymentDate` | string | ❌ | 그 달 결제일. `YYYY-MM-DD`. **Path의 `year`·`month`와 같은 달**이어야 한다 |
| `content` | string | ❌ | 그 달 내용 |
| `paymentMethodId` | number | ❌ | 그 달 수단. 본인 소유의 `purpose=EXPENSE` 수단이어야 한다 |

> 고정지출 **이름**과 **지출유형**은 이 API로 바꾸지 않는다. 고정지출 관리([4.4 `FixedExpenseUpdate`](./4.4-FixedExpenseUpdate.md))에서 바꾼다.

### Headers

| 이름 | 필수 | 설명 |
|------|:----:|------|
| `Authorization` | ✅ | `Bearer <accessToken>` |
| `Content-Type` | ✅ | `application/json` |

## 응답

### 성공 (`resCode: 200`) — `data`

[4.5 `FixedExpenseMonthlyList`](./4.5-FixedExpenseMonthlyList.md)의 `list[]` 요소와 동일 구조 (수정 후 값, `modified`는 항상 `true`).

### 실패 — 대표 `resCode`

| resCode | 조건 |
|---------|------|
| 1001 | 로그인 필요 |
| 3401 | 금액·결제일·수단 검증 실패, 또는 바꿀 필드가 하나도 없음 |
| 3402 | 고정지출 없음(또는 내 것이 아님) |
| 3403 | year·month 범위 오류 |
| 3405 | 그 연·월의 고정지출 내역이 아직 없음 |

## 예시

### 성공

**Request**

```http
PATCH /api/v1/fixed-expenses/monthly/2026/7/1 HTTP/1.1
Host: localhost:8081
Authorization: Bearer eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
Content-Type: application/json

{
  "amount": 550000,
  "paymentDate": "2026-07-10",
  "content": "7월만 관리비 포함"
}
```

**Response**

```json
{
  "resCode": 200,
  "data": {
    "fixedExpenseId": 1,
    "year": 2026,
    "month": 7,
    "fixedExpenseName": "월세",
    "amount": 550000,
    "paymentDate": "2026-07-10",
    "content": "7월만 관리비 포함",
    "paymentMethodId": 1,
    "paymentMethodName": "국민카드",
    "expendGroupId": 2,
    "expendGroupName": "주거",
    "modified": true
  }
}
```

### 실패

```json
{
  "resCode": 3405,
  "data": {
    "message": "해당 연월의 고정지출 내역이 없습니다"
  }
}
```

## 비고

- **그 달 행을 직접 고친다.** 별도의 "월별 예외" 저장 단위는 없다(구 `FixedExpenseMonthlyOverrideUpsert` 대체).
- 수정한 행은 `modified = true`가 되어, 이후 고정지출 관리 값을 바꿔도 **덮어써지지 않는다**. 관리 값으로 되돌리려면 [4.9 `FixedExpenseMonthlySync`](./4.9-FixedExpenseMonthlySync.md)를 `overwriteModified=true`로 호출한다.
- `3405`가 나오면 그 달이 아직 한 번도 조회되지 않은 것이다. [4.5](./4.5-FixedExpenseMonthlyList.md)로 조회하거나 [4.9](./4.9-FixedExpenseMonthlySync.md)로 재작성한 뒤 다시 시도한다.
- 이 API는 **고정지출 내역만** 고친다. 일반 지출 수정은 3.x `ExpenseUpdate`를 쓴다.
