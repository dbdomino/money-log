## 1. 실행

화면과 백엔드를 함께 띄운다. **백엔드에는 PostgreSQL 이 필요하다.**

```bash
./gradlew :app-mod:money-backend-app:bootRun   # :8081
./gradlew :app-mod:money-app:bootRun           # :8080
```

008 부터는 **백엔드가 떠 있어야 화면이 의미 있게 동작한다.** 007 은 백엔드 없이도 확인할 것이
있었지만(주소 연결·권한 없음 화면) 008 의 화면 9개는 전부 백엔드를 부른다.

백엔드가 꺼져 있으면 각 화면은 007 의 오류 화면으로 착지한다 — 그 자체가 007 FR-606 의 확인이다.

## 2. 손으로 밟아 보는 경로

`http://localhost:8080` 에서 시작한다. 로그인하지 않았으면 로그인 화면으로 간다.

### US1 — 가입하고 로그인한다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 로그인 화면에서 「가입」으로 간다 | 가입 폼. **비밀번호 규칙이 입력 전에 보인다** |
| 2 | 폰에 `010-1234-5678` 을 넣고 가입한다 | 가입 성공 → 로그인 화면. **아이디가 채워져 있다** |
| 3 | 같은 아이디로 다시 가입한다 | `2002` 가 **아이디 칸 가까이**. 닉네임·이메일 입력이 남아 있다 |
| 4 | 비밀번호와 확인을 다르게 넣는다 | `2005`. 비밀번호 두 칸만 비어 있고 나머지는 남아 있다 |
| 5 | 틀린 비밀번호로 로그인한다 | `1003`. **아이디 칸에는 아무 표시도 없다** |
| 6 | 맞는 값으로 로그인한다 | 월별 가계부 주소로 간다 (010 이 만들 화면이라 아직 없다) |
| 7 | 본인 정보로 가서 폰을 확인한다 | **하이픈 없이 숫자만** 저장돼 있다 |
| 8 | 상단바에서 로그아웃한다 | 로그인 화면. 보호 주소가 다시 막힌다 |

### US2 — 잃어버린 계정을 되찾는다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 아이디 찾기에 가입 이메일을 넣는다 | 같은 화면에 아이디가 나온다. 가려져 오면 그 사실이 적혀 있다 |
| 2 | 없는 이메일로 찾는다 | `2001` |
| 3 | 비밀번호 찾기에 아이디·닉네임을 넣는다 | 비밀번호 변경 화면. **아이디·닉네임을 다시 묻지 않는다** |
| 4 | 규칙에 못 미치는 비밀번호로 저장한다 | `2004`. **같은 화면에 머물고 다시 시도할 수 있다** |
| 5 | 규칙에 맞는 비밀번호로 저장한다 | 같은 화면에 완료 문구 → 로그인 화면 |
| 6 | 새 비밀번호로 로그인한다 | 성공 |
| 7 | 주소창에 `/auth/reset-password` 를 직접 친다 | 폼이 아니라 **비밀번호 찾기로 안내** |

### US3 — 본인 정보를 고친다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 본인 정보를 연다 | 현재 값이 채워져 있다. **아이디는 고칠 수 없다** |
| 2 | 새 비밀번호를 비운 채 닉네임만 바꿔 저장한다 | 닉네임만 바뀐다. 비밀번호는 그대로라 **옛 비밀번호로 로그인된다** |
| 3 | 이메일을 지우고 저장한다 | **비워진다.** 다시 열면 빈 칸이다 |
| 4 | 남이 쓰는 이메일로 저장한다 | `2003` 이 이메일 칸 가까이 |

### US4 — 관리자가 회원을 관리한다

관리자 계정이 필요하다. 002 의 시험 자료나 DB 에서 권한을 올려 둔다.

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 관리자로 로그인해 사이드바를 본다 | **회원 관리 메뉴가 보인다** |
| 2 | 회원 목록을 연다 | 행·쪽 정보가 뜬다. 열은 여섯이고 **가입일이 없다** |
| 3 | 아이디 칸에만 검색어를 넣는다 | 아이디로 좁혀진다. 쪽 번호가 첫 쪽이다 |
| 4 | 아이디·닉네임에 함께 넣는다 | **둘 다 맞는 회원만** 나온다. 화면에 그 설명이 적혀 있다 |
| 5 | 다음 쪽으로 넘긴다 | 검색어가 유지된 채 이어진다. 겹치는 행이 없다 |
| 6 | 「회원 추가」로 회원을 만든다 | 목록에 나타난다. 권한 선택지는 **둘뿐**이다 |
| 7 | 「수정」을 누른다 | **그 회원 값이 채워진 채로** 모달이 열린다 |
| 8 | 주소에 `?m=edit&id=없는아이디` 를 친다 | 오류 화면이 아니라 **목록이 정상으로** 뜬다 |
| 9 | 「정지」를 누른다 | 확인 다이얼로그. **되돌릴 수 없다는 것과 재로그인 불가**가 적혀 있다 |
| 10 | 확인해 정지한다 | 상태가 정지로 바뀐다. **「해제」 버튼은 없다** |
| 11 | 정지한 계정으로 로그인한다 | `1004` |
| 12 | 자기 자신을 정지하려 한다 | 확인 본문에 **본인이라는 사실**이 적혀 있다 |
| 13 | 일반 권한으로 로그인해 `/admin/members` 를 친다 | 권한 없음 화면. 사이드바에 메뉴가 없다 |

### 007 을 고쳐야 하는 경우

008 은 007 의 공통 코드를 고치지 않는 것이 전제다. 다만 **007 의 결함이 드러나면 그쪽을 고친다.**
지금 알고 있는 후보가 하나다.

| 후보 | 확인 방법 |
|---|---|
| 세션이 끝났을 때 007 이 실어 보내는 안내 문구가 로그인 화면에 닿는가 | 1.1 을 세운 뒤 그 경로를 시험으로 건다. 닿지 않으면 **007 의 전달 방식**을 고친다 — 문구를 넘기는 것은 007 의 책임이고 화면이 맞춰 줄 일이 아니다 |
