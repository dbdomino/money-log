# Contract: 본인 정보 (1.7)

**Feature**: 008-frontend-member-auth | **관련 FR**: 715~717

| 항목 | 값 |
|---|---|
| 주소 | `/member/profile` |
| 껍데기 | 007 의 **로그인 후** 레이아웃 (사이드바 + 상단바) |
| 사이드바 활성 메뉴 | `profile` |
| 권한 | 로그인 |
| 부르는 API | `MemberGetMe`(조회) · `MemberUpdateMe`(저장) |

로그인 후 화면 중 008 이 만드는 유일한 개인 화면이다. 진입 판정은 007 이 이미 한다 — 이 화면은
세션이 살아 있다는 전제로만 그려진다.

---

## 1. 조회

화면이 열릴 때마다 백엔드에서 현재 값을 받는다. **세션에 담아 두지 않는다** — 관리자가 그 회원을
고쳤을 때 화면에 옛 값이 남는다.

| 칸 | 채워지는 값 | 고칠 수 있나 |
|---|---|---|
| 아이디 | 로그인 아이디 | **아니다.** 읽기 전용으로 보인다 (FR-715) |
| 닉네임 | 현재 닉네임 | 그렇다 |
| 이메일 | 현재 이메일. 없으면 빈 칸 | 그렇다 |
| 폰 | 현재 폰. 숫자만 | 그렇다 |
| 소개 | 현재 소개. 없으면 빈 칸 | 그렇다 |
| 새 비밀번호 | **언제나 빈 칸** | 그렇다 |
| 권한 | — | **화면에 고르는 자리를 두지 않는다.** 본인은 자기 권한을 바꿀 수 없다 |

아이디를 읽기 전용으로 두는 것만으로 부족하지 않다 — 백엔드 수정 API 에 아이디를 바꾸는 칸 자체가
없다. 화면은 그 사실을 사용자에게 보여 줄 뿐이다.

**새 비밀번호 칸에 "변경할 때만 입력"을 적는다.** 비어 있는 것이 정상 상태라는 것을 사용자가 알아야
한다.

---

## 2. 저장

브라우저는 `POST` 로 보내고 화면 모듈이 백엔드의 수정 요청으로 옮긴다(research 8).

### 빈 칸을 어떻게 보낼 것인가

**칸마다 뜻이 다르다.** 이것이 이 화면의 핵심 규칙이다(research 7).

| 칸 | 비어 있으면 | 요청에 |
|---|---|---|
| 새 비밀번호 | **바꾸지 않는다** (FR-716) | **싣지 않는다** |
| 이메일 | **비운다** | 빈 값으로 싣는다 |
| 폰 | **비운다** | 빈 값으로 싣는다 |
| 소개 | **비운다** | 빈 값으로 싣는다 |
| 닉네임 | (필수라 비울 수 없다) | 언제나 싣는다 |

새 비밀번호만 다른 이유는 **그 칸만 현재 값이 채워지지 않은 채 뜨기 때문**이다. 비어 있는 것이 기본
상태이므로 "비웠다"가 아니라 "건드리지 않았다"로 읽는 것이 맞다.

나머지 셋은 현재 값이 채워진 채로 뜬다. 사용자가 지웠다면 지우려는 뜻이다. 이것을 "유지"로 읽으면
사용자는 이메일을 지우고 저장했는데 그대로 남아 있는 화면을 보게 된다.

### 폰

하이픈을 넣어도 **화면 모듈이 걷어내 숫자만 보낸다**(FR-703 · SC-704). 브라우저 스크립트에 맡기지
않는다 — 스크립트가 막힌 환경에서 하이픈이 그대로 나가 형식 오류로 거절된다.

### 결과

| 결과 | 화면 |
|---|---|
| 성공 | 저장된 값을 화면에 반영하고 완료를 알린다 |
| `2003` 이메일 중복 | **이메일 칸 가까이** (FR-717) |
| `2004` 비밀번호 규칙 위반 | **새 비밀번호 칸 가까이** (FR-717) |
| `9001` | 폼 상단 |

실패해도 **새 비밀번호 칸을 뺀 나머지 입력이 남는다**(form-failure.md §3).

**닉네임을 바꿔도 로그인 세션은 그대로다.** 세션이 들고 있는 것은 아이디와 권한뿐이고 둘 다 본인
수정으로 바뀌지 않는다. 상단바의 표시가 아이디라면 바뀌지 않는 것이 맞다.

---

## 3. 시험으로 고정할 것

| 항목 | 근거 |
|---|---|
| 화면에 현재 값이 채워져 있고 아이디 칸이 읽기 전용이다 | FR-715 |
| 새 비밀번호를 비우면 백엔드 요청에 비밀번호가 **실리지 않는다** | FR-716 |
| 이메일을 비우면 백엔드 요청에 **비우라는 값이 실린다** | research 7 |
| 하이픈을 넣은 폰이 숫자만으로 나간다 | FR-703 · SC-704 |
| `2003` 이 이메일 칸 가까이 붙는다 | FR-717 |
| 실패 응답에 비밀번호 평문이 **없다** | SC-708 |
| 미로그인으로 열면 로그인 화면으로 간다 | 007 FR-618 |
