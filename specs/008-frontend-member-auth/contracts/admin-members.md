# Contract: 관리자 회원 관리 (1.8~1.10)

**Feature**: 008-frontend-member-auth | **관련 FR**: 718~724

| 화면 | 주소 | 표시 |
|---|---|---|
| 1.8 회원 목록 | `/admin/members` | 페이지 |
| 1.9 회원 추가 | `/admin/members?m=create` | 목록 위 모달 |
| 1.10 회원 수정 | `/admin/members?m=edit&id={아이디}` | 목록 위 모달 |

| 항목 | 값 |
|---|---|
| 껍데기 | 007 의 **로그인 후** 레이아웃 |
| 사이드바 활성 메뉴 | `admin-members` (세 화면 모두) |
| 권한 | **관리자** |
| 부르는 API | `AdminMemberList` · `AdminMemberCreate` · `AdminMemberGet` · `AdminMemberUpdate` · `AdminMemberDeactivate` |

**권한 판정은 007 이 한다.** 일반 권한으로 이 주소에 오면 진입 판정이 권한 없음 화면으로 보내고,
로그인하지 않았으면 로그인 화면으로 보낸다 — 그 순서가 007 의 요구사항이다. 008 은 사이드바에
메뉴를 **그리지 않는 쪽**만 맡는데, 그것도 007 의 사이드바가 권한을 보고 이미 처리한다(FR-724).

## 1. 목록 (1.8)

### 검색은 두 칸이다

| 칸 | 필수 | 뜻 |
|---|:---:|---|
| 아이디 | ❌ | 부분 일치 |
| 닉네임 | ❌ | 부분 일치 |

**둘을 함께 넣으면 둘 다 맞는 회원만 나온다.** 백엔드가 두 조건을 AND 로 묶기 때문이다
(research 5). 화면에 그 사실을 한 줄로 적는다 — 적지 않으면 관리자는 "또는"으로 기대하고 결과가
비었을 때 데이터가 없다고 읽는다.

프로토타입의 칸 하나짜리 검색은 쓰지 않는다. 한 값을 두 조건에 똑같이 실으면 "아이디에도 있고
닉네임에도 있는" 회원만 걸린다.

### 쪽 넘기기

007 의 환산기가 쪽 번호를 백엔드가 요구하는 조회 구간으로 바꾼다. 화면이 직접 계산하지 않는다.

| 항목 | 규칙 |
|---|---|
| 쪽 번호 | 0 부터. 주소에 실린다 |
| 검색 폼 | **쪽 번호를 싣지 않는다.** 새 검색은 언제나 첫 쪽이다 (FR-719) |
| 쪽 이동 링크 | 쪽 번호와 **검색어 두 개를 함께** 싣는다. 빠뜨리면 쪽을 넘길 때 검색이 풀린다 |
| 전체 쪽 수 | 백엔드가 준 전체 건수로 환산한다. 현재 쪽의 행 수가 아니다 |

### 열

| 열 | 값 |
|---|---|
| 아이디 | 로그인 아이디 |
| 닉네임 | |
| 이메일 | 없으면 빈 칸 |
| 권한 | 관리자 / 일반. 숫자 대신 말로 보인다 |
| 상태 | 활성 / 정지 |
| 관리 | 「수정」 · 「정지」 |

**가입일 열을 두지 않는다.** 백엔드 목록 응답에 그 값이 없다(research 12). 프로토타입에는 있지만
응답에 없는 값을 열로 두면 빈 칸이 "가입일을 모르는 회원"으로 읽힌다.

**정지된 회원에게 「해제」를 두지 않는다.** 정지를 되돌리는 API 가 없다(research 11). 누를 수 없는
버튼을 두면 관리자는 언제든 되돌릴 수 있다고 믿고 정지를 누른다.

## 2. 회원 추가 (1.9)

목록 위 모달이며 `?m=create` 로도 열린다.

| 칸 | 필수 | 비고 |
|---|:---:|---|
| 아이디 | ✅ | |
| 비밀번호 | ✅ | 규칙 문구를 칸 아래에 적는다 |
| 닉네임 | ✅ | |
| 권한 | ✅ | **관리자와 일반 두 값만** 고를 수 있다 (FR-721). 자유 입력을 두지 않는다 |
| 이메일 | ❌ | |
| 폰 | ❌ | 숫자만 보낸다 |
| 소개 | ❌ | |

**비밀번호 확인 칸이 없다.** 백엔드 생성 API 가 확인 값을 받지 않는다 — 가입(1.2)과 다른 점이며,
관리자가 만든 임시 비밀번호를 회원에게 알려 주는 흐름이기 때문이다.

| 결과 | 다음 |
|---|---|
| 성공 | 목록을 다시 그린다. 만든 회원이 목록에 보인다 |
| `2002` 아이디 중복 | 아이디 칸 |
| `2003` 이메일 중복 | 이메일 칸 |
| `2004` 비밀번호 규칙 위반 | 비밀번호 칸 |
| `9001` 권한 값 오류 | 폼 상단 |

실패하면 **모달을 연 채로** 목록 화면을 다시 그린다(form-failure.md §6).

## 3. 회원 수정 (1.10)

`?m=edit&id={아이디}` 로 열린다. **모달을 열기 전에 서버가 그 회원을 조회한다**(research 9).

| 칸 | 채워지는 값 | 고칠 수 있나 |
|---|---|---|
| 아이디 | 대상 아이디 | **아니다.** 읽기 전용 |
| 닉네임 | 현재 값 | 그렇다 |
| 권한 | 현재 값이 골라진 채로 | 그렇다. 두 값만 |
| 이메일 | 현재 값 | 그렇다. 비우면 지운다 |
| 폰 | 현재 값 | 그렇다. 비우면 지운다 |
| 소개 | 현재 값 | 그렇다. 비우면 지운다 |
| 새 비밀번호 | **언제나 빈 칸** | 그렇다. 비우면 바꾸지 않는다 |

빈 칸의 뜻은 본인 정보(1.7)와 같다 — 새 비밀번호만 "유지"이고 나머지는 "비움"이다.

| 상황 | 결과 |
|---|---|
| 조회 성공 | 모달이 값이 채워진 채로 열린다 |
| 조회 `2001` 회원 없음 | **오류 화면이 아니라** 모달 없이 목록만 보이고 안내를 띄운다. 낡은 북마크일 뿐이고 목록은 정상이다 |
| 식별자 없이 `?m=edit` | 모달을 열지 않고 목록만 보인다 |
| 저장 성공 | 목록을 다시 그린다 |
| 저장 실패 | 모달을 연 채로 해당 칸에 붙인다 |

## 4. 회원 정지

| 항목 | 내용 |
|---|---|
| 부르는 곳 | 목록 행의 「정지」 |
| 확인 | 007 의 **공통 확인 다이얼로그**를 쓴다 (FR-722) |
| 보내는 방법 | `POST`. 되돌릴 수 없는 동작을 링크로 두면 브라우저가 미리 불러오는 것만으로 실행된다 |
| 결과 | 목록을 다시 그린다. 그 회원의 상태가 정지로 바뀐다 |

### 확인 다이얼로그 본문에 담을 것

다이얼로그는 문구를 만들지 않고 부르는 화면이 넘긴다(007 의 규약). 세 가지를 담는다.

1. **대상이 누구인지** — 아이디와 닉네임.
2. **되돌릴 수 없다는 사실** — 화면에서 정지를 푸는 길이 없다(research 11).
3. **정지와 로그아웃이 다르다는 것** — 정지된 계정은 **다시 로그인할 수 없다**(FR-723).
   로그아웃은 토큰만 무효로 만들고 다시 로그인할 수 있다.

**대상이 자기 자신이면 그 사실을 함께 알린다**(FR-722 · Edge Case). 관리자가 자기를 정지하면 다음
요청부터 자기도 막힌다.

| 실패 | 보이는 것 |
|---|---|
| `2001` 회원 없음 | 목록을 다시 그리며 안내 |
| `9001` 이미 정지 상태 | 목록을 다시 그리며 안내. 오류 화면으로 보내지 않는다 |

## 5. 시험으로 고정할 것

| 항목 | 근거 |
|---|---|
| 관리자로 목록을 열면 행과 쪽 정보가 그려진다 | FR-718 |
| 아이디·닉네임 검색어가 백엔드 요청에 **각각** 실린다 | research 5 |
| 검색 폼에 쪽 번호가 없어 새 검색이 첫 쪽에서 시작한다 | FR-719 |
| 쪽 이동 링크에 검색어 둘이 함께 실린다 | §1 |
| `?m=create` 로 들어오면 추가 모달이 열린 채 목록이 뜬다 | FR-720 |
| `?m=edit&id=…` 로 들어오면 **그 회원의 값이 채워진 채** 모달이 열린다 | research 9 |
| 모르는 식별자면 모달 없이 목록이 정상으로 뜬다 | §3 |
| 권한 선택지가 관리자와 일반 **둘뿐**이다 | FR-721 |
| 정지가 `POST` 이고 확인 다이얼로그를 거친다 | FR-722 |
| 확인 본문에 되돌릴 수 없다는 것과 재로그인 불가가 적혀 있다 | FR-723 · research 11 |
| 대상이 본인이면 그 사실이 본문에 적힌다 | FR-722 |
| 목록 응답 HTML 에 「가입일」과 「해제」가 **없다** | research 11 · 12 |
| 일반 권한으로 세 주소를 열면 권한 없음 화면이다 | FR-724 · SC-705 |
