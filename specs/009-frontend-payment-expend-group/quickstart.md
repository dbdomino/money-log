## 1. 실행

화면과 백엔드를 함께 띄운다. **백엔드에는 PostgreSQL 이 필요하다.**

```bash
./gradlew :app-mod:money-backend-app:bootRun   # :8081
./gradlew :app-mod:money-app:bootRun           # :8080
```

**로그인 없이는 아무 화면도 열리지 않는다.** 008 이 만든 로그인으로 들어간 뒤 사이드바의
「지출·소득 수단」·「지출유형」으로 간다.

가입 직후 계정에는 **기본 지출유형이 이미 들어 있다.** 그것이 3장의 검증 대상이다.

## 2. 손으로 밟아 보는 경로

### US1 — 수단을 관리한다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 수단 목록을 연다 | 표가 뜬다. 열은 여섯이고 **유효기간 열이 없다** |
| 2 | 「수단 등록」을 눌러 카드로 고른다 | **유효기간 칸이 나타난다** |
| 3 | 구분을 계좌로 바꾼다 | **유효기간 칸이 사라진다** |
| 4 | 용도를 고르지 않고 저장한다 | 저장되지 않고 그 칸을 채우라는 안내가 뜬다 |
| 5 | 카드·지출용으로 채워 저장한다 | 목록에 나타난다. 구분과 용도가 **말로** 보인다 |
| 6 | 「상세」를 누른다 | 값이 읽기 전용으로 보인다. **입력 칸이 없다** |
| 7 | 상세에서 「수정」을 누른다 | 수정 모달로 넘어가고 주소가 바뀐다 |
| 8 | 그 수단으로 지출을 등록한 뒤 용도를 바꿔 저장한다 | 거절되고 **용도 칸 가까이** 사유가 뜬다. 고른 값이 그대로 남아 있다 |
| 9 | 「삭제」를 누른다 | 확인 다이얼로그. **과거 내역의 이름은 남는다**가 적혀 있다 |
| 10 | 확인해 삭제한다 | 목록에 **남아 있고** 상태가 「삭제됨」이다 |
| 11 | 그 행을 본다 | **수정·삭제 버튼이 없고 상세만 있다** |

### US2 — 지출유형을 관리한다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 지출유형 목록을 연다 | 가입 때 생긴 기본 유형들이 보이고 구분이 「기본」이다 |
| 2 | 기본 유형의 「수정」을 연다 | **이름 칸이 잠겨 있다** |
| 3 | 기본 유형 행을 본다 | **삭제 버튼이 없다** |
| 4 | 「유형 등록」에서 아이콘 파일을 고른다 | **저장 전에 미리보기가 보인다** |
| 5 | 1MB 를 넘는 파일로 저장한다 | 거절되고 **허용 형식과 크기가 다시 안내된다** |
| 6 | 확장자만 `png` 로 바꾼 파일로 저장한다 | 서버가 내용으로 판정해 거절한다 |
| 7 | 맞는 파일로 저장한다 | 목록에 아이콘과 함께 나타난다 |
| 8 | 이름만 바꿔 저장한다 | **아이콘이 그대로 남는다** |
| 9 | 아이콘 없이 유형을 만든다 | 목록에서 **이미지가 깨지지 않고** 대체 표시가 나온다 |
| 10 | 그 유형으로 지출을 등록한 뒤 삭제한다 | 거절되고 **「사용 안 함으로 돌리라」는 대안**이 함께 뜬다 |
| 11 | 삭제한 유형과 같은 이름으로 새로 만든다 | 중복으로 거절되고 **삭제된 이름도 센다**가 안내된다 |

### US3 — 목록에서 상태를 구분해 본다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 수단 하나를 사용 안 함으로 바꾼다 | 목록에서 「사용 안 함」이고 상태는 「정상」이다 |
| 2 | 다른 수단을 삭제한다 | 사용 열과 **다른 열**에 「삭제됨」이 보인다 |
| 3 | 주소에 `?m=edit&id=` + 없는 번호를 친다 | 오류 화면이 아니라 **목록이 정상으로** 뜨고 안내가 보인다 |
| 4 | 주소에 `?m=edit` 만 친다 | 모달 없이 목록만 보인다 |

### 아이콘이 어떻게 오는지 본다

| # | 하는 것 | 기대 |
|---|---|---|
| 1 | 목록 페이지의 소스를 본다 | 이미지 주소가 **화면 모듈 경로**다. 백엔드 주소가 없다 |
| 2 | 브라우저 네트워크 탭을 본다 | 아이콘 요청이 `:8080` 으로만 나간다. `:8081` 로 직접 나가지 않는다 |
